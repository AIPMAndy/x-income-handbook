# 05 · Premium 要不要买

> 按功能购买，别把订阅当成投资回报承诺。

## 为什么要做

X 订阅分 Basic、Premium、Premium+ 等层级，价格按地区和支付渠道变化；蓝标需账号审核。新版原创奖励要求符合资格的套餐。

## 具体操作

1. 在 X 官方订阅页核对当前所在地和渠道的实际价格，不使用过期价目表作预算。
2. 先确认你真正需要的功能：长帖、编辑、可申请创作者功能等；免费账号也能先验证内容定位。
3. 订阅后到设置查看订单与蓝标审核状态；付款成功与审核通过是两件事。
4. 设 30 天复盘标准：具体功能是否提高产出效率或带来可归因的业务机会。

## 场景演练｜Premium 是费用，不是收益权

购买会员后蓝标可能需要审核；即使认证完成，也不代表订阅或 Original Content Rewards 已获准。购买前列出是否真的用到长帖、可见度、工具额度等具体功能。

### 跟着做

1. 进入 X 当前付款页核对你真实账号能购买的档位、当地价格、自动续费方式。
2. 把月费计入获客实验成本：如果没有明确用途，先不把它当作增长捷径。
3. 到 Creator Studio 查看创作者功能是否可用，截图记录与会员状态分开。

### 完成标准

形成「购买原因 + 预算上限 + 下月复核日」记录。

### 卡住时怎么处理

若充值后没有蓝标：到账号设置检查资料、审核提示和申诉入口，不要通过频繁修改身份信息解决。

## 常见误区

- 相信买会员=买曝光
- 为了身份认证伪造居住地、身份、付款材料
