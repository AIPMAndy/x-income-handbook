# 21 · 海外收款与真实身份

> 账户资格先于收款工具选择。

## 为什么要做

平台奖励的支付提供方、支持地区、身份税务信息与第三方交易收款条件是不同问题。不要用不真实的地址/身份规避限制。

## 具体操作

1. 先核对本人真实常住地、税务身份、付款资格及收款账户支持范围。注意：截至 2026-10-24，中国大陆未被列在 X Original Content Rewards 的公布地区清单中；不要用香港或美国假身份代替资格。
2. 平台计划在账号 Creator Studio 完成对应验证：美国地区流程与非美地区可能不同。
3. 服务和产品通过合法合规的收款商户处理，保留发票、合同及交易记录。
4. 处理跨境税务与外汇问题时咨询有资质的专业人士，避免把教程当成具体法律或税务意见。

## 场景演练｜收款资格优先于换 IP

X Money、Stripe 或合作平台对真实身份、地区和税务有要求。VPN 出口、公司注册地、居住地和税务居民身份是不同概念。

### 跟着做

1. 先确认谁作为法律上的收款主体：个人/企业、常住地、可提供文件、银行支持情况。
2. 对官方奖励按不同地区核查 X Money / Stripe 实际可用性；对自有服务单独查看平台服务协议、发票与税费。
3. 制定到账对账记录：订单编号、原币、汇率、手续费、退款、税务凭证。

### 完成标准

真实身份的收款流程清单，不公开任何银行卡/身份证号。

### 卡住时怎么处理

若通道不支持本人的真实地区，就更换合规的商业模式或咨询持牌专业人士，拒绝借身份和地址绕过。

## 常见误区

- 购买假身份、假地址、代收款账户
- 默认 USDT 转账符合所有合同、税务或当地法律要求
