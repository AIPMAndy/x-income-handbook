# 23 · 刷量、群发、AI 搬运的真实代价

> 系统性风险先排除，再扩大生产规模。

## 为什么要做

X 对虚假互动、重复内容、自动群发、抄袭与欺骗性行为有明确约束。2026 新原创奖励计划还对自动化发布的内容、专门讨论最大化收益的内容作出限制。

## 具体操作

1. 写一份编辑审核清单：原创来源、素材权利、人工事实核查、是否商业合作、是否包含客户隐私。
2. 自动化优先用于资料整理、草稿协作和排期提醒；发布行为遵守 X 自动化规则。
3. 对比同一主题的不同内容，杜绝跨账号批量发布高度重复文案。
4. 遇到收益资格或审核异常，保留错误截图并通过官方申诉，不找「包过」黑产。

## 场景演练｜把风控写成发布前的检查动作

高频复制同一推广回复、多账号重复贴、刷互动、群发陌生 DM 都可能触发平台限制；使用 AI 写草稿也必须由真人核事实和版权。

### 跟着做

1. 发帖前核实：原创贡献、数据来源、图片版权、客户隐私、是否付费合作、是否适用禁推品类。
2. 为有报酬合作启用 Paid Partnership 及必要披露；财经/加密等禁推广领域先检查政策边界。
3. 禁止自动化刷赞/评论/群发，不向公开仓库上传任何 API key。

### 完成标准

发布前 6 项勾选表，出现红线则不发布。

### 卡住时怎么处理

若账号被限制，停止导致风险的行为，保存通知与证据，使用官方申诉，不购买“解封服务”。

## 常见误区

- 一键转推群、互赞群、粉丝交易
- 让机器人连续发未经审核的同质化内容
