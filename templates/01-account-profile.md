# 账号主页四件套

## 1. 昵称与定位
- 昵称：___
- 受众：___
- 解决的问题：___
- 我可以公开展示的证明：___（必须真实且有权限）

## 2. 英文 Bio 模板
I help [specific audience] with [specific problem] using [method].
Sharing [deliverable type] + [verifiable proof].
[link]

示例（占位，不代表作者履历）：I share practical AI workflows for product managers. Real demos and checklists below.

## 3. 置顶帖结构
我是谁 → 我研究/服务的具体问题 → 3 个自己做的作品 → 哪些人可以关注 → 进一步了解的官方/个人链接。

## 4. 上线前检查
- [ ] 头像及图片有使用权
- [ ] 不冒用公司身份/地点
- [ ] 置顶链接真的可以访问
- [ ] 没有假履历或收入截图
