# 有价值的评论模板（禁止批量群发）

先读原帖，确认自己有具体补充。

- 补充型：One thing I'd add: [specific nuance]. This mattered when [true, non-confidential situation].
- 反例型：I see the point, but [specific counterexample]. It changes the decision if [condition].
- 方法型：For anyone trying this, I'd check [step 1] before [step 2].

不写「Check DM」「Follow me」「Great post」之类无效评论。不使用机器人批量评论，不向陌生人无差别发送消息。
