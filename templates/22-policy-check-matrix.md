# X 两类平台变现的资格清单（核验于 2026-10-24）

> 本表适用于教学自检；以 Creator Studio 的账号资格状态和最新官方政策为准。

| 核验维度 | Original Content Rewards | Creator Subscriptions |
|---|---|---|
| 账户状态 | 良好且持续原创 | 账号良好，近 30 天有发帖 |
| 账号年龄 | 依该计划官方最新规则 | 至少活跃 3 个月 |
| 身份年龄 | 18+ | 18+ |
| 合格会员 | 官方列出的 Premium/Premium+ 等 | 官方列出的 Premium/Premium+ 等 |
| 曝光 | 近 90 天 ≥ 500,000（50 万） verified users Home Timeline 曝光；回复不计申请门槛 | 近 3 个月 ≥ 5,000,000（500 万）自然曝光 |
| 粉丝 | ≥ 500 位 verified followers | ≥ 2,000 位拥有合格 Premium 的活跃粉丝 |
| 地区/支付 | 必须满足明确的适用地区和出款资格 | 应核对所在地区、身份、实际产品权限和支付资格 |
| 审核 | 满足门槛不代表获批 | 满足门槛不代表获批 |

**易混淆**：基础会员 Basic 能否为其他人的原创帖子贡献 qualified impressions，不能推导该 Basic 账号本身可申请该奖励；申请人付费套餐资格单独按官方标准检查。

**出款**：新版原创奖励官方目前写明美国使用 X Money，非美国使用 Stripe，并有身份核验与最低出款额限制。这并不意味着 Stripe 可以服务任何国家的任何人。

**特别提醒**：X 官方明确说明“专门围绕赚钱教学、赚钱讨论或最大化奖励”的内容不符合当前 Original Content Rewards 的合格内容范围。因此，运营“X 赚钱教程”类账号时，不要假设这类教学帖可以获得官方原创奖励。

**商单品类审查**：Paid Partnerships 不允许推广金融产品、服务、投资机会（包括加密货币）、赌博等限制品类。即使已经披露 Paid Partnership，也不能自动合法。
