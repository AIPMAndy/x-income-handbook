# 6 个不编造事实的 X 中英双语发帖范本

所有方括号必须填入自己的真实信息。不要把演示案例写成已有客户业绩。

## 1. 求职咨询类：观点
中文：我看了[真实数量]份[岗位类别] JD。很多人简历写了“做过 AI”，但面试官会继续问：你具体负责了什么？能拿出什么证据？
英文：I reviewed [actual number] job postings for [role]. “Worked on AI” sounds nice, but what did you own? What can you show?

## 2. AI 工具：开发日志
中文：我今天给[工具名称]砍掉一个功能。原因很简单：[真实用户反馈]。上线功能不难，有人持续用才难。
英文：I removed a feature from [product] today. [Real user feedback] made the decision pretty clear. Shipping is easy. Getting repeat use is harder.

## 3. 真实经验：反思
中文：以前我以为[原判断]。后来做了[真实经历]，发现[新的可验证判断]。这次我会先验证[下一步]。
英文：I used to think [old belief]. Then I tried [real experience]. What changed my mind was [specific observation]. Next, I'll test [next step].

## 4. 资料分享：清单
中文：整理了一张[目标场景]检查表，主要解决[具体痛点]。免费放这里：[实际链接]。里面也写了它不适用的情况。
英文：I put together a checklist for [scenario]. It helps with [problem]. Free here: [real link]. I also included when *not* to use it.

## 5. 负面反馈：产品讨论
中文：有人告诉我[授权或匿名反馈]。这个反馈提醒我，[问题]还没有解决。我准备先改[具体一点]。
英文：A user pointed out [anonymized feedback]. Fair point. [Issue] is still not solved. I'm fixing [specific thing] first.

## 6. 询问问题：真诚讨论
中文：我最近在研究[真实项目]。如果你遇到过[明确问题]，你目前是怎么解决的？
英文：I'm working on [real project]. If you've dealt with [specific issue], how do you handle it today?

**发布前**：查证英文版本是否扩大了原文承诺；有任何商业合作/返佣要披露。不要批量发送相同内容。
